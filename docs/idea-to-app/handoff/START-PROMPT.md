# Start-Prompt für das Coding-Tool

> Der Code existiert bereits. Kopiere den Text als erste Nachricht in dein Coding-Tool (Claude Code, Cursor, Copilot, Codex …), geöffnet im Repository `Multimodell-Chat`.

```text
Du arbeitest im bestehenden Repository „Multimodell-Chat“.

1. Lies zuerst docs/idea-to-app/handoff/AGENTS.md vollständig. Die Regeln dort – besonders Abschnitt 5 „Nicht verhandelbare Sicherheitsregeln“ – gelten für jede Aufgabe.
2. Lies danach docs/idea-to-app/handoff/docs/produkt.md, architektur.md, sicherheit.md und roadmap.md.
3. Führe npm ci, npm run typecheck, npm test und npm run test:rls aus und melde das Ergebnis.
4. Fasse mir in maximal 10 Zeilen zusammen, was du verstanden hast, und nenne Unklarheiten oder Widersprüche zwischen Unterlagen und Code.
5. Kläre mit mir die offenen Annahmen aus AGENTS.md Abschnitt 6 – eine Frage nach der anderen.
6. Beginne dann mit der ersten offenen Aufgabe aus docs/roadmap.md (TASK-018). Arbeite eine Aufgabe nach der anderen ab.
7. Wenn du vom Plan abweichen musst, halte dich an AGENTS.md Abschnitt 7.

Ich bin Entwickler. Wenn ich etwas tun muss (z. B. ein Konto bei einem Dienst anlegen oder einen Schlüssel eintragen), erkläre mir die Schritte genau – und sag mir, wo der Schlüssel hingehört, ohne dass ich ihn dir in den Chat schreiben muss.
```
