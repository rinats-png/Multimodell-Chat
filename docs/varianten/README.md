# Zehn Design-Varianten (Stand 2026-10-30)

Alle Varianten zeigen denselben Chat-Screen der echten App. Sie entstehen durch eigene Stilregeln über dem aktuellen Design (Skript nicht eingecheckt).

| Nr | Name | Thema | Kern |
|---|---|---|---|
| 01 | Abgeschrägt · Amber | dunkel | gekappte Ecken an Rahmen, Karten, Buttons; Amber-Gold; Großbuchstaben-Titel |
| 02 | Clu-Rot · Scanlines | dunkel | Rot-Orange, Bildschirm-Scanlines, dicke Glühkanten |
| 03 | Moos · Raster | dunkel | gedämpftes Grün, sichtbares Lichtraster, eckig |
| 04 | Terminal | dunkel | Mono-Schrift überall, keine Rundungen, Scanlines |
| 05 | Hologramm | dunkel | fast durchsichtige Panels, starkes Glühen, Blur 34 px |
| 06 | Wireframe | dunkel | nur Linien, keine Flächen, Hintergrund sichtbar |
| 07 | Schwebende Module | dunkel | kein großer Rahmen, drei getrennte Panels |
| 08 | Elfenbein & Kupfer | hell | Kupferlinien auf Elfenbein |
| 09 | Sand · Orange scharf | hell | kräftiges Orange, 2 px Kanten |
| 10 | Hell-Terminal | hell | Mono, eckig, harte Braunlinien, kein Glühen |

Übernommen ist keine davon. Die App zeigt das überarbeitete aktuelle Design (kantiger, stärkere Lichtkante mit wandernder Leuchtbahn).
